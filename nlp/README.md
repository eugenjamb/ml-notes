# NLP Notes

For now, this directory covers only foundational text preprocessing.

Start with the examples in `text_preprocessing/`:

1. `text_cleaning_and_tokenization_example.py`
2. `text_normalization_and_placeholders_example.py`
3. `sentence_word_and_ngram_tokenization_example.py`
4. `stop_words_and_frequency_filtering_example.py`

These examples are self-contained and require no corpus downloads. More NLP
topics can be added later after the preprocessing foundation is complete.
